# Djaoued-Cg Brand – Music Library

One shared link. Anyone with it can listen, upload songs, download songs and delete songs (trash button).

- Live: https://music-library-rose.vercel.app
- Songs are stored in Vercel Blob (`music/` folder); the file names are the song titles.
- Local run: `npm install && npm start` (files go in `./data`). 
- Deploy: `npx vercel deploy --prod`
